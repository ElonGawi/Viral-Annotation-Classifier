# inPhormer: Model Development and Exploration Repository
This repository contains the model development and evaluation work that led to the final models integrated into the [inPhormer Python package](https://github.com/Mila-MP/inPhormer). It documents the exploratory phase of the project, during which multiple modeling strategies, architectures, and hyperparameters were evaluated.

The work was carried out by Cara Eidsmo Holt, Elon Gawi-Matok, and Mila Pertuy as part of the Integrated Bioinformatics Project in the Master of Bioinformatics program at KU Leuven.
